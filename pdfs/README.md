# Product PDFs

Rendered by `pdf-viewer.html` via PDF.js. Add the two product documents here
with these exact filenames:

- `pgt-vinyl-windows.pdf` — PGT Vinyl Windows
- `pgt-aluminum-windows.pdf` — PGT Aluminum Windows

The viewer only loads files that are registered in the `DOCS` map in
`js/pdf-viewer.js`, keyed by the `?file=` value (for example
`pdf-viewer.html?file=pgt-vinyl-windows`). To add another document, drop the
file here and add a matching entry to that map.
